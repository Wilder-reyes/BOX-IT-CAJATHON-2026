## Cómo usar este espacio

1. **Antes del desafío:** revisar reglas, acordar roles, investigar y documentar capacidades.
2. **Al recibir el desafío:** confirmar restricciones de divulgación; analizarlo fuera del repositorio público si es confidencial.
3. **Al definir Solution Concept:** completar solo información autorizada y documentar tecnología preexistente.
4. **Durante la presencial:** registrar desarrollo nuevo, pruebas y resultados verificables.
