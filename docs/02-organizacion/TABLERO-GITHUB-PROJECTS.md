# Seguimiento de tareas

Los GitHub Issues son el mecanismo principal. GitHub Projects es opcional y **aún no está creado**.

## Para crear el tablero
1. En GitHub, crear un nuevo Project tipo Board.
2. Nombre sugerido: **BOX-IT | Cajathon 2026**.
3. Estados: Backlog, Por hacer, En progreso, En revisión, Terminado.
4. Campos sugeridos: Responsable, Revisor, Fecha, Prioridad, Enlace de evidencia.
5. Vincular Issues de este repositorio y definir responsables al conocer sus usuarios GitHub.

## Criterio de cierre
Una tarea se considera terminada cuando tiene entregable verificable y al menos una revisión cruzada.

No publicar información confidencial, reto no autorizado o datos de usuarios reales en Issues del repositorio público.
