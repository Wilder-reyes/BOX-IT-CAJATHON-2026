## Cómo registrar una decisión nueva

```text
Fecha:
Tema:
Alternativas:
Decisión del equipo:
Motivos y criterios:
Responsable:
Cuándo revisarla:
```

No registrar datos privados, acuerdos confidenciales o información del reto que no esté autorizada para publicación.
