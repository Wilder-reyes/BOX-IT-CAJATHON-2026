# Colaboración de BOX-IT

## Acuerdos iniciales
- El reto de Negocios NO se conoce todavía.
- El coordinador registrado no es automáticamente líder general. El liderazgo se elegirá por acuerdo del equipo.
- Cada tarea tendrá responsable, fecha, revisor, evidencia y criterios de aceptación.
- Evitar cargas de trabajo basadas únicamente en los perfiles; confirmar disponibilidad.
- No subir información personal real, credenciales, datos internos ni comunicaciones confidenciales a este repositorio público.

## Flujo Git
1. Abrir o comentar Issue.
2. Crear rama con nombre descriptivo: `docs/...`, `chore/...` o `feat/...` cuando exista el reto.
3. Abrir Pull Request con contexto, fuentes y evidencias.
4. Solicitar revisión cruzada antes de fusionar a `main`.
5. Anotar componentes de terceros y licencias, sin incorporar activos de otros proyectos sin permiso.

## Fase presencial
Preservar el estado previo al 3 de diciembre y registrar commits, pruebas y evidencias de las adaptaciones o funcionalidades desarrolladas durante el evento. Ningún prototipo preexistente, por sí solo, cumple la condición de funcionalidad crítica nueva.
